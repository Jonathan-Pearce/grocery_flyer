# Grocery Flyer Frontend

Vue 3 + Vite application for browsing weekly grocery deals and viewing chain-level flyer rankings.

## Routes

- `/` - onboarding flow (postal code, map, store selection)
- `/deals` - ranked deal cards for selected stores
- `/rankings` - weekly chain leaderboard and recent history

## Data inputs

The app reads static JSON files generated by the backend pipeline into `frontend/public/data/`:

- `active_scores.json` - scored deal rows
- `stores_geo.json` - store-level location metadata used by map/store selector
- `flyer_regions.json`, `chain_regions.json`, `postal_centroids.json` - regional helpers
- `rankings.json`, `rankings_history.json` - chain ranking snapshots

Generate/update these files from repo root:

```bash
python scripts/run_pipeline.py
# or, if db outputs are already current:
python scripts/export_frontend_data.py
```

## Local development

From `frontend/`:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Notes

- Routing uses hash history (`createWebHashHistory`) for GitHub Pages compatibility.
- If the UI shows empty/error state for deals or rankings, refresh generated JSON outputs first.
